# 发版冒烟清单（M9-5）

> 用途：每次发版前，在一台真机上按下面的顺序走一遍，逐项记录结果。清单不是走过场——
> 它的价值在于「失败项有证据、有处置决定」，以及「这一版能不能发」有一个书面结论。
>
> 底稿是 `06` §4 的十六项动作序列；后面几组是发行相关项。
